## spec 第九节局限与不能越界的论断

| 局限 | 报告必须说清的边界 | 可操作后续工作（不计本次必做） |
| --- | --- | --- |
| OPT 状态爆炸 | 默认深度 3、候选上限 K=24；深度 4 理论上界更高，分治/裁剪后只在固定模型内最优 | 更强上下界、迭代加深和计时预算，先做无剪枝基准 |
| HARD 仅人类隐藏 | AI 有底层 TrueMap；MIN 人类策略候选仅由 ViewMap 生成；对真实玩家外推有限 | 双向未知陷阱的信念状态/POMDP 是额外项目 |
| 分治近似 | 跨块通过全图 BFS 验证合法性，但局部关注目标仍会丢全局策略 | 估计误差与加速比双轴报告，优化块划分/跨块候选 |
| 贪心短视 | 比率不含人类策略、对战和陷阱风险；胜率不保证提高 | 作为简单模式的教学基线，不偷加博弈策略 |
