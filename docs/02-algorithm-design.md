# 02｜算法设计与可证边界

> 规则/数值约定见 [00](00-framework.md)，全部签名只以 [01](01-module-contracts.md) 为准。下文 `V=height×width`、`E≤4V`、`T` 为剩余宝藏数、`L` 为活动陷阱数、`d` 为剩余**玩家回合**数、`K=24` 为默认每个决策节点候选上限。所有策略返回 `MoveSequence`，真实结果一律交由 `PathModule.sim_player_multi_step(true_map, start_pos, move_seq, max_valid_step)` 决定。

## 1. BFS、连通与贪心（EASY）

| 阶段 | 确定规则 | 验证点 |
| --- | --- | --- |
| 地图校验 | `PathModule.bfs_distances` 从出生点 A 出发，要求所有非墙格距离存在，出生点 B 不同且空 | 允许陷阱/宝物所在格通行；越界/墙不入队 |
| 寻宝 | 从当前机器座位 BFS 到各剩余宝藏，仅考虑可达者 | 距离是成功移动数，不按撞墙尝试数计 |
| 性价比 | `value / max(distance,1)`；距离为 0 的目标按 1 防零除（出生点原则上空）；比较用整数交叉相乘避免浮点误差 | `value>=2`，**不**扣除沿途陷阱期望、不看人类座位 |
| 平局 | 比率高者优先；其次宝藏分值高；其次距离短；其次目标 `(row,col)` 字典序小 | 选择稳定，种子只影响地图/骰子 |
| 输出 | `PathModule.bfs_path(true_map,start,target)` 得邻序上/左/下/右的最短路径，将相邻坐标差映为 Direction，取前 `dice_N` 条；无宝藏/不可达返空 | 按 Path 内核重放，若沿途另有宝物先触发并在返回图中消失 |

复杂度：单次 BFS `O(V+E)` 时间、`O(V)` 空间；扫描 `T` 个宝藏 `O(T)`，路径恢复 `O(V)`，总 `O(V+E+T)` 时间、`O(V)` 空间。正确性要点：BFS 同权图按层首次访问为最短成功步距离；交叉相乘给出完全确定的最大收益/距离；前缀长度不超过骰步且路径各步合法。**局限**：这不是全局最优收益策略，不会考虑宝藏争抢、对战或陷阱损失，报告不要误称贪心具有博弈意识。

## 2. OPT Expecti-Max（NORMAL/HARD）

### 节点、价值、状态转移

| 节点 | 输入 | 取值/下一节点 |
| --- | --- | --- |
| `MAX` | 当前行动者为机器 AI，骰子 `N` 已知 | 遍历合法序列候选，对 `U=scoreOpt−scoreHuman` 取最大；轮末经 Path → Battle → 终局检测 |
| `MIN` | 当前行动者为人类模型，骰子 `N` 已知 | 候选**只由 ViewMap** 和公开分数生成，随后在 TrueMap 上执行；对 AI 效用 `U` 取最小 |
| `CHANCE` | 下一座位回合之前 | 六个骰值 1..6 各权重 `1/6`，均值；根骰子已知，不再掷一次 |
| 叶 / 游戏结束 | 深度 0 或宝藏耗尽 | 报告约定 `eval=scoreHuman−scoreOpt`；搜索内部 `U=−eval=scoreOpt−scoreHuman`；无额外未声明潜力项 |

机机对局的行动 AI 在 A 时临时规范化座位：当前 AI=Opt/MAX、对手=Human/MIN；`GameState` 本体不交换资源和坐标，计算输出再映射回 A，报告中的 `scoreHuman/scoreOpt` 指**当前搜索树两方的角色**。OPT 不接收实际对手策略参数：不论机机对手实际为贪心或 OPT，MIN 均按配置的有限**视图策略集**近似，因此对手模型偏差应在报告说明。对于相等 U 的合法候选，先比较到最近可达宝藏的 BFS 距离较短者，再比较成功步数较少者，最后按 Direction 顺序上/左/下/右的序列字典序；这只破平局，**不改变** `eval` 定义。

候选生成按回合最多 N 个**有效**动作：空序列、朝宝藏 BFS 路径前缀、靠近/远离对手、局部可达终点及其短路径；小地图正确性基线穷举长度 `0..N` 的四方向序列并按完整结果去重；大图按确定性启发式排序保留最多 K 条，保留空动作和宝藏前缀。墙碰撞的冗余动作在优化候选中省略（Path 仍支持人类撞墙）；每个候选通过 Path 核与 Battle 计算**逐步取物、回合末对战**，将新图与分数/揭示信息传入下一层。HARD 人类候选绝不能按隐藏真值挑“安全”动作；潜在陷阱在它真正经过时才进入其后续视图。

### 人类行为模型与可解释性

| 模型 | 作为主实现？ | 防信息泄露及报告口径 |
| --- | --- | --- |
| **有限策略集上的最坏情况** | 是（D5）：候选为视图上最短寻宝、收益/距离、躲敌、停步；MIN 在集合中选对 AI 最差的**真实后果** | 动作集合生成不接触 `TrueMap`；AI 预测人类踩坑可能性不等于人类知道坑 |
| 所有合法方向序列上的最坏情况 | 小图敏感性/穷举基线 | 仅用视图合法格（隐藏陷阱呈空地）；组合数较大 |
| 有限理性 / 概率人类 | 报告扩展，不混入主结论 | 若采用温度 softmax，需要额外标定，改变 MIN 为期望节点，另列实验 |

名称“OPT”仅为规格模块名：**限深/裁剪/人类模型下的最优**，不是信息不完全博弈全局最优。`AiModule.get_opt_move(state, dice_N)` 返回确定方向序列；`get_diagnostics()` 的根预测终点必须等于在相同状态下 Path 再执行一次的终点。

### 安全 α-β、机会节点与记忆化

MAX/MIN 的 `alpha`、`beta` 是 AI 效用 U 的下/上界；每个机会子节点真实可能效用有保守范围 `[lo,hi]`。可取当前 `U0` 加减 `R=Σ剩余宝藏|value|+Σ活动陷阱|value|+10d` 得全子树 `[U0-R,U0+R]`（一次对战最大改变双方分差 10，最多 d 个后续回合）。该界宁宽勿错；两玩家未来踩取资源总计最多一次。已计算概率质量贡献为 `S=Σ p_i×U_i`，未展开总概率为 `q`，机会节点的合法区间为 `[S+q×lo, S+q×hi]`；若上界 `<=alpha`（其 MAX 祖先已有更好选择）或下界 `>=beta`（MIN 祖先已有更差选择），**只可在正确传递窗口下**中止当前分支，返回带 `LOWER/UPPER` 标记的界，绝不能当精确期望。安全初版：每个 chance **枚举六面并对其子树传全窗口 `(-∞,+∞)` 求精确值**；父 MAX/MIN 只对已求得的精确子值做 α-β 兄弟剪枝。加入 chance 区间剪枝时应实现界类型与窗口传播证明，并先和全枚举版在小图逐状态对照。任何缓存命中只针对精确值，界/超时/部分展开不准存为精确 DP。

精确 DP key：`(map_id, canonical_actor_seat, pos_human, pos_opt, score_human, score_opt, frozenset(remaining_treasures), frozenset(active_traps), frozenset(revealed_traps), turn, node_kind, known_dice_or_None, remaining_depth, mode, human_model_id, candidate_limit, partition_context)`；其中资源值及墙通过 `map_id` 固定，`partition_context` 防止局部子问题与全图混用。`map_id` 由规范静态字节串指纹计算，而非进程不稳定的内置 hash。未来可用位图替代 frozenset，但测试必须证明 key 一一对应。记录每轮 `cache_hits/cache_misses/nodes`，命中率 `hits/(hits+misses)`，零分母记 0；跨不同地图/模型/深度不可复用。搜索时间由单次 `perf_counter_ns` 记，缓存容量默认按每次动作清零避免无界增长。

复杂度：一骰的原始指令序列 `b_N=Σ(k=0..N)4^k`，最大 `b_6=5461`；根骰已知、每层其后带 6 面机会节点，未经去重上界为 `O(b_6^d 6^(d−1) × (N+V+E))`，深度 3/4 已不可用。裁剪到 K 后节点数上界 `O(K(6K)^(d−1))`：`K=24` 时深度 3 为 `497,664`，深度 4 为 `71,663,616` 个叶级分支上界；单候选 Path 最多 6 步、Battle `O(1)`，若叶平局时 BFS 再加 `O(V+E)`。递归栈 `O(d)`；记忆表最坏 `O(K(6K)^(d−1) × (T+L))` 存储 key；去重/α-β只改善实测，不保证降低最坏指数级。深度 4 仅在有预算与小图基准通过后启用，默认 3；实际耗时/节点须实验验证。

正确性要点：对固定有限搜索树进行回合归纳，叶值为 `−eval`；MAX/MIN 选择极值，chance 用概率加权；Path/Battle 为唯一转移。α-β 只淘汰不可能改变父节点选择的分支，chance 的 `S+q×[lo,hi]` 保守覆盖未知结果；相同完整 key 的精确子树可重用。剪枝版必须与相同候选集的无剪枝版结果（值与确定平局动作）一致，否则禁用优化。

## 3. 分治分块（仅大地图 OPT）

| 步骤 | 设计 | 必须测量 |
| --- | --- | --- |
| 切分 | 默认图面积 `V>=144` 时按确定性 4×4 近似矩形块（边缘允许不足）；地形只作“关注资源”划分，不改变全图坐标与可通行性 | 块数、每块资源数、连通跨块边数 |
| 跨块 | 用全图 BFS 求各块入口与块内目标的最短路；若目标不在当前块，保留到入口的方向前缀；任何跨块路径都经全图 Path 验证 | 不可达资源绝不作为有效候选；穿越的其他资源真实触发 |
| 子问题 | 向 `solve_local(state,dice_N, allowed_positions)` 传局部关注宝藏集合；子树仍持有完整 TrueMap/两人状态，局部集合**只限制候选目标**，不删掉真实墙/陷阱/宝藏或对手 | 局部预测与全图核对相等 |
| 合并 | 汇总各块候选、全局空动作与跨块前缀，对每条候选用全图 Path→Battle 评分；采用相同 U/平局规则选本回合动作 | 每个返回序列在全图合法、步数≤N |

设块数 `C`、每块候选至多 `K_c`、每块允许目标数量 `T_c`，全图 BFS 一次 `O(V+E)`，生成最多 `ΣK_c` 候选，局部搜索上界 `Σ O(K_c(6K_c)^(d−1))`，合并 `O((ΣK_c)N)`；空间 `O(V+E+Σ局部缓存)`。这是**近似**，局部目标约束及逐块评分会漏掉跨块长远互动；不能仅凭合法性声称接近最优。比较相同地图/骰序/人类策略下单体 OPT（小图可穷举）与分治版的根效用差 `ΔU=U_mono−U_partition`（可正可负）和 `|ΔU|`、动作一致率、胜率差及加速比 `time_mono/time_partition`；记录中位数与 p95，若预算外超时则标记 censored、不把缺失值填 0。报告覆盖阈值附近的 10×10、12×12、14×14 图，阈值只作为工程默认而非已证最优。

## 4. 复杂度与验证入口汇总

| 算法 | 时间上界 | 空间上界 | 关键自动验证 |
| --- | --- | --- | --- |
| BFS/连通 | `O(V+E)` | `O(V)` | 全部非墙格可达、最短层次单调 |
| Path 单回合 | `O(len(move_seq)+N(T+L))` 保守（资源集合拷贝时；达到 N 即停，静态底图共享） | `O(T+L+len(events))` 新集合/事件额外空间；底图共享 | 撞墙不耗有效步，途中即时触发 |
| 贪心 | `O(V+E+T)` | `O(V)` | 枚举比率与 tie-break 选中同一目标 |
| OPT | `O(K(6K)^(d−1)×(N+V+E))` 保守 | 指数表项 × key 大小 | 与无剪枝穷举同值/同平局动作 |
| 分治 | `O(V+E+ΣK_c(6K_c)^(d−1))` | `O(V+E+Σ缓存)` | 全图重放、近似误差/加速比 |

> 所有复杂度为保守上界；真实缓存量、候选数、剪枝数、耗时在 [04](04-test-plan.md) 的固定环境与种子下记录，不把理论上界冒充性能实测。
